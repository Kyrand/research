# Example Documentation Investigation

This is an example research project demonstrating the documentation-heavy pattern.
Projects of this type focus on investigating a topic, collecting findings, and
producing a written report with supporting evidence.

## Background

This project was created as a template to illustrate the structure of a
documentation-focused research investigation in this repository.

## Findings

- Each research project lives in its own top-level directory
- At minimum, projects contain `README.md` (the report) and `notes.md` (the process log)
- Code snippets or extracted artifacts can be included as separate text files
- The `_summary.md` file is auto-generated and should not be created manually

## Methodology

1. Identify the research question
2. Investigate using available tools and resources
3. Document findings in `notes.md` as work progresses
4. Compile final results into this `README.md`
