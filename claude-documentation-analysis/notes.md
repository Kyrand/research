# Notes: CLAUDE.md Documentation Analysis

## Goal

Analyze the repository structure and conventions to create a comprehensive CLAUDE.md file that helps AI assistants understand the codebase and work effectively within it.

## Repository Analysis

### Structure

This is a **research repository** (cloned from the simonw/research pattern) where each top-level directory is a self-contained research project carried out by an LLM tool (usually Claude Code). Every line of text and code is written by an LLM.

### Key files at the root level

- `CLAUDE.md` — Currently just `@AGENTS.md` (a reference/include). Needs expansion.
- `AGENTS.md` — Contains instructions for AI agents about how to structure their work.
- `README.md` — Auto-generated index of all research projects using cogapp + LLM summaries.
- `requirements.txt` — Python dependencies: cogapp, llm, llm-github-models.
- `.gitignore` — Ignores .DS_Store, __pycache__, node_modules, package.json/lock, .pyodide-xbuildenv.
- `.github/workflows/update-readme.yml` — CI workflow that runs cogapp to update README.md on push to main.

### Example project patterns observed

1. **Documentation-heavy** (`example-documentation-investigation/`):
   - README.md (final report) + notes.md (process log)
   - No executable code

2. **Code-heavy** (`example-code-project/`):
   - README.md + notes.md
   - Python source files + tests
   - Standard Python conventions (pytest-style tests)

### Conventions identified

- Each research project is a self-contained top-level directory
- Minimum files: `README.md` (report) + `notes.md` (process log)
- `_summary.md` is auto-generated by cogapp + LLM — never create manually
- Code should follow standard Python conventions
- Don't include full copies of fetched code — only new files or diffs
- Binary files allowed if < 2MB
- No vendoring external dependencies
- Tests placed alongside source code

### CI/CD

- GitHub Actions workflow runs on push to main
- Uses Python 3.11
- Runs `cog -r -P README.md` to regenerate the project index
- Uses `llm` CLI with `github/gpt-4.1` model to generate summaries
- Auto-commits changes back to the repository

### Dependencies

- `cogapp` — Code generation tool used for README templating
- `llm` — CLI tool for LLM interactions
- `llm-github-models` — Plugin for GitHub-hosted models

## Approach

Will write a comprehensive CLAUDE.md that:
1. References AGENTS.md (preserving the existing behavior)
2. Documents repository structure and purpose
3. Explains the research project workflow
4. Lists key conventions and constraints
5. Documents the CI/CD pipeline
6. Provides guidance on common tasks
