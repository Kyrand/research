# CLAUDE.md Documentation Analysis

This investigation analyzed the repository structure and conventions to produce a comprehensive `CLAUDE.md` file that helps AI assistants work effectively within this research repository.

## Background

The existing `CLAUDE.md` contained only a single line: `@AGENTS.md`. While `AGENTS.md` provides core workflow instructions for research projects, it lacks broader context about the repository's structure, CI/CD pipeline, code conventions, and development environment that would help AI assistants be more effective.

## Methodology

1. Examined all root-level files: `CLAUDE.md`, `AGENTS.md`, `README.md`, `requirements.txt`, `.gitignore`
2. Analyzed the CI/CD workflow in `.github/workflows/update-readme.yml`
3. Studied both example project templates to understand the two project patterns
4. Identified all conventions, constraints, and tooling

## Changes Made

The updated `CLAUDE.md` now includes:

- **`@AGENTS.md` reference preserved** — The existing include directive remains as the first line, so all AGENTS.md instructions continue to apply
- **Repository overview** — Explains the purpose: an AI research repository where each directory is a self-contained LLM-authored project
- **Directory structure diagram** — Visual tree showing the layout and purpose of each file/directory
- **Research project workflow** — Step-by-step guide for creating new research projects
- **Project type descriptions** — Documents both the documentation-heavy and code-heavy patterns with their expected file contents
- **Commit rules** — What to include and exclude from commits, consolidating rules from AGENTS.md with additional context
- **CI/CD pipeline documentation** — Explains the GitHub Actions workflow that auto-generates README.md and _summary.md files
- **Development environment** — Python version, testing framework, and tooling details
- **Code conventions** — PEP 8, pytest patterns, file naming, and project self-containment

## Key Findings

- The repository uses `cogapp` to template the root README.md with embedded Python that lists all projects by date
- Project summaries are generated by the `llm` CLI tool using the `github/gpt-4.1` model
- The `_summary.md` files are cached and auto-committed by CI — agents must never create these manually
- The `.gitignore` already accounts for Python, Node.js, and macOS artifacts
- Both example projects demonstrate consistent patterns that new projects should follow
