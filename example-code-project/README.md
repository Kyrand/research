# Example Code Project

This is an example research project demonstrating the code-heavy pattern.
Projects of this type involve writing and testing code as part of the investigation.

## Overview

This project was created as a template to illustrate the structure of a
code-focused research project in this repository.

## Implementation

The project includes a simple Python module (`example_module.py`) and a test
file (`test_example.py`) to demonstrate the typical code project structure.

## Results

- Code projects include source files alongside the standard README.md and notes.md
- Build files (Makefile, etc.) can be included when relevant
- Tests help validate findings and demonstrate functionality
- External dependencies should be documented but not vendored into the repo
